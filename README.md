## Hi there

I'm **Zeyad**, a Software Development Engineer based in El Sheikh Zayed, Giza, Egypt.

I focus on full-stack development and practical engineering — building efficient, scalable solutions while sharpening problem-solving and communication. I enjoy shipping work that goes beyond demos: APIs, UIs, containers, and real delivery.

Some of the things I've built and shipped include **DNS-FastEdge Grafana plugins** at Orange Business, mentoring software engineering at **Nile University**, and **Derma Assist** — an AI-powered mobile app for early skin-problem detection.

I'm especially interested in backend systems, DevOps, Go, and product features that solve real problems. Outside of work, I keep learning cloud, Kubernetes, and system design.
